# Платформа профориентации через диалог — пакет подготовки

AI-собеседник, который через интервью, наводящие вопросы и конкретные примеры
помогает человеку понять, **каким делом ему заниматься и на чём зарабатывать** —
выводя на 3–5 **конкретных профессий или занятий** (не «направление»), включая
наём, фриланс и своё дело. Прошлый опыт — плюс, но не ограничение.

Этот репозиторий содержит **всю подготовку перед сборкой бота**: исследование,
методологию диалога, промпт, алгоритмы, схему данных и стартовый каталог.

📋 **Дорожная карта разработки по фазам — в папке [`plan/`](plan/README.md)**
(9 фаз: фундамент → данные → бот → матчинг → UX → приватность → тесты → запуск →
рост). Что ещё собрать — [`plan/still-to-collect.md`](plan/still-to-collect.md).
Открытые вопросы — [`plan/open-questions.md`](plan/open-questions.md).

🚀 **Рабочий MVP уже собран** (Next.js + Claude API). Запуск:

```bash
npm install
cp .env.example .env.local   # вписать ANTHROPIC_API_KEY
npm run dev                  # http://localhost:3000
```

Что внутри MVP: чат с двумя режимами (быстрый/глубокий), бот на «ты» по сценарию,
извлечение профиля, матчинг по каталогу из 24 ролей, итоговые карточки профессий
с первым шагом, перехват кризисных сигналов. Код: `app/` (UI+API), `lib/` (движок),
`data/catalog.json` (каталог). Сессии на MVP — in-memory; в проде заменяются на
Supabase (схема в `migrations/`).

## Как всё связано

```
Пользователь ↔ Бот (system-prompt.md, по сценарию dialogue-script.md)
                 │  извлекает теги по profile-extraction-rubric.md
                 ▼
           user_profile (sessions.profile, схема 0001_init.sql)
                 │  needs_catalog_query
                 ▼
           Матчинг (matching-algorithm.md) по каталогу
                 │  (наполнен из data-sourcing.md, seed 0002/0003)
                 ▼
           3–5 конкретных профессий → отчёт + первый шаг
```

## Открытые вопросы к владельцу продукта

1. **Рынок и язык:** только РФ/русский или сразу мультиязычно? (влияет на
   локализацию данных, 152-ФЗ vs GDPR).
2. **Аудитория:** школьники/студенты, взрослые в смене карьеры, все? (меняет
   акценты сценария).
3. **Монетизация:** бесплатно/подписка/разовый отчёт/B2B (школы, hr)?
4. **Глубина самозанятости:** насколько сильно тянуть людей в своё дело против
   найма по умолчанию?
