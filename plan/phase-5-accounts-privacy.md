# Фаза 5 — Аккаунты, согласие и приватность

> Цель: легально и безопасно собирать чувствительные данные (интересы, навыки,
> доход, жизненная ситуация). Закладывается с самого начала, дорабатывается тут.

## Результаты фазы

- Auth (Supabase Auth): email/OAuth; возможны анонимные сессии.
- Экран согласия на обработку ПДн до начала диалога.
- Политика конфиденциальности и пользовательское соглашение.
- Механизм удаления сессии/профиля по запросу пользователя.
- Настройки приватности у LLM-провайдера (данные не идут в обучение).
- Шифрование at-rest/in-transit, минимизация собираемых данных.

## Задачи

- [x] Экран/чекбокс согласия + версия согласия (`lib/consent.ts`, `CONSENT_VERSION`).
- [x] Серверный гейт согласия (`/api/session` возвращает 400 без согласия) — проверено.
- [x] Тексты политики приватности (`docs/privacy-policy.md` + страница `/privacy`).
- [x] Функция «удалить мои данные» (`DELETE /api/session/[id]` + кнопка в UI).
- [ ]💳 Подключить Supabase Auth; связать `users` ↔ `sessions` (после создания проекта).
- [ ]🔑 Подтвердить, что Anthropic API не использует данные для обучения.
- [ ]👤 Юр-вычитка политики и реквизиты оператора; РФ-152-ФЗ (место хранения ПДн).

## Что собрать / решить

- Юрисдикция и применимый закон (из Фазы 0: рынок).
- Где хранить ПДн (для РФ — серверы в РФ).
- Платёжные данные (если монетизация — отдельный контур, PCI у провайдера).
- Возрастная политика (если школьники — согласие родителей).

## Зависит от

Фаза 0 (рынок/закон). Базовое согласие нужно уже в Фазе 4 (лендинг).

## Критерий готовности

- Нельзя начать диалог без согласия.
- Пользователь может удалить свои данные.
- Хранение и обработка соответствуют закону выбранного рынка.
- LLM-провайдер настроен на необучение на данных.

## Риски

- Школьники как аудитория → строже требования (согласие родителей) — учесть в
  Фазе 0.
