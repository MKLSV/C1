# План разработки платформы профориентации — дорожная карта

Платформа = AI-собеседник, который через интервью, наводящие вопросы и примеры
выводит человека на **3–5 конкретных профессий/занятий** (наём, фриланс, своё
дело), исходя из того, что ему нравится и на чём он может зарабатывать.

Этот каталог (`plan/`) разбивает проект на **9 фаз** — от подготовки до роста.
Подготовительные материалы (исследование, промпт, схема БД, каталог) уже готовы
и лежат в [`/docs`](../docs) и [`/migrations`](../migrations) — см.
[корневой README](../README.md).

## Критический путь к работающему MVP

```
Фаза 0 (решения) → Фаза 1 (каталог+БД) → Фаза 2 (бот) → Фаза 3 (матчинг)
                                              ↓
                                         Фаза 4 (UX) → Фаза 5 (приватность)
                                              ↓
                                    Фаза 6 (тесты) → Фаза 7 (запуск)
```

**Минимальный MVP** (что показать первым пользователям): Фазы 0→1(частично, на
готовом каталоге из 24 ролей)→2→3→4(базовый чат). Аккаунты/платежи/импорт O*NET
можно отложить.

## Принципы, которые держим во всех фазах

1. **Конкретика, а не направления.** Всегда выводим на конкретную роль.
2. **Наём и своё дело равноправны.** Самозанятость — не довесок.
3. **Прошлый опыт — плюс, не рамка.** Желаемое дело не обязано быть связано с ним.
4. **Диалог, а не анкета.** Следующий вопрос зависит от предыдущего ответа.
5. **Данные, а не выдумки.** Доход/спрос — из каталога, помечены как ориентир.
6. **Безопасность и приватность с первого дня.** Согласие, без обещаний дохода,
   мягкая обработка кризиса.

## Как пользоваться этим планом

- Каждая фаза самодостаточна: цель → результаты → задачи → что собрать/решить →
  зависимости → критерий готовности → оценка.
- Перед стартом фазы — закрыть её блок «что решить» (см. open-questions.md).
- Отмечайте задачи прямо в файлах фаз (чекбоксы).
