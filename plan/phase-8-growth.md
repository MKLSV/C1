# Фаза 8 — Рост и развитие

> Цель: после запуска — повышать качество, удерживать актуальность данных и
> расширять ценность.

## Направления развития

### Качество и данные
- [ ] Регулярное обновление зарплат/спроса в `income_profiles` (устаревают).
- [ ] Расширение каталога (новые профессии, ниши, тренды AI-рынка).
- [ ] Постоянная калибровка весов матчинга на реальных реакциях.
- [ ] Дообучение формулировок вопросов (A/B по `questions`).

### Новые фичи
- [ ] Личный кабинет: история сессий, сравнение, динамика.
- [ ] Повторные сессии и отслеживание прогресса по «первым шагам».
- [ ] План развития под выбранную профессию (курсы, ресурсы, дорожная карта).
- [ ] Сообщество/менторы, связь с реальными специалистами.
- [ ] Голосовой режим диалога.
- [ ] Интеграция с биржами/вакансиями (показ реальных заказов/вакансий по роли).

### Масштаб и рынки
- [ ] Мультиязычность (ESCO как многоязычная основа навыков).
- [ ] Новые рынки (локализация данных о доходе и закона).
- [ ] B2B-направление: кабинеты для школ/вузов/HR, аналитика по группам.

### Аналитика и бизнес
- [ ] Когортная аналитика, удержание, конверсия в оплату.
- [ ] Оптимизация стоимости токенов (модель/кэш/суммаризация истории).
- [ ] Партнёрства (образование, карьерные сервисы).

## Зависит от

Запущенного продукта (Фаза 7) и потока реальных данных.

## Критерий «здоровья» (метрики, за которыми следим постоянно)

- Доля сессий с финалом и оценка «попадания» рекомендаций.
- Доля рекомендаций, по которым сделан «первый шаг» (если отслеживаем).
- Свежесть данных о доходе (дата последнего обновления).
- Стоимость одной сессии (токены) vs выручка.
