## Что решить (блокирует следующие фазы)

См. подробно в [open-questions.md](open-questions.md). Кратко:
1. **Рынок и язык** → влияет на локализацию данных и закон (152-ФЗ vs GDPR).
2. **Аудитория** → акценты сценария (школьники / смена карьеры / своё дело).
3. **Монетизация** → нужны ли платежи/кабинеты в MVP.
4. **Tech-стек** — подтвердить рекомендацию (Next.js + Supabase + Claude API + Vercel).
5. **Глубина «своего дела»** — насколько активно тянуть в самозанятость.
