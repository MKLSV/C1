# Фаза 2 — Ядро диалога (MVP бота)

> Цель: рабочий разговорный движок — бот ведёт интервью по сценарию, тёпло
> общается и параллельно собирает структурированный профиль. Это «мозг» продукта.

## Результаты фазы

- Эндпоинт `/api/turn` — обрабатывает один ход диалога.
- Интеграция Claude API с системным промптом из `docs/system-prompt.md`.
- Парсинг и валидация JSON-ответа модели (`reply` + `profile_patch` + флаги).
- **Profile merger** — слияние `profile_patch` в `sessions.profile`
  (deltas суммируются, массивы дополняются, constraints перезаписываются).
- Сохранение `messages` и обновление `sessions`.
- Обработка кризисных сигналов (safety filter) до показа ответа.

## Задачи

- [ ] Каркас бэкенда (Next.js API routes или отдельный сервис).
- [ ] Клиент Claude API (модель Opus 4.8 для качества; Sonnet 4.6 — эконом-режим).
- [ ] Сборка контекста хода: system-промпт + история (усечение) + полный профиль
      + (опц.) каталог из матчинга.
- [ ] Парсер JSON-ответа + ретрай при невалидном JSON (1 повтор).
- [ ] Profile merger с правилами слияния (см. system-prompt.md §«Как бэкенд…»).
- [ ] Логика этапов и условия `ready_to_finalize`.
- [ ] Safety filter: детектор кризиса → спец-ответ + ресурсы помощи.
- [ ] Prompt caching на системный промпт (снижение стоимости).
- [ ] Юнит-тесты merge-логики; «прогон» эталонного диалога из example-transcript.

## Что собрать / решить

- API-ключ Anthropic (Claude API). Лимиты/бюджет на токены.
- Решение по модели: Opus везде vs Opus на гипотезы + Sonnet на простые ходы.
- Список кризисных триггеров и ресурсов помощи (телефоны/службы по региону).
- Политика хранения истории (сколько ходов держать в контексте).

## Зависит от

Фаза 1 (каталог — чтобы `needs_catalog_query` возвращал реальные роли) и Фаза 0
(язык промпта, аудитория). Может вестись параллельно с Фазой 1 на каталоге из 24
ролей.

## Критерий готовности

- Бот проходит полный сценарий 0→6 на тестовых репликах.
- Профиль корректно накапливается (проходит чек-лист из profile-extraction-rubric §7).
- Невалидный JSON не роняет ход (есть ретрай/фолбэк).
- Кризисный кейс перехватывается и не идёт «как обычно».

## Оценка

Основная инженерная фаза MVP. Параллелится с Фазой 1.
