# Фаза 1 — Данные и каталог профессий

> Цель: развернуть БД и наполнить каталог конкретными профессиями (наём + своё
> дело) с навыками, доходом, путями входа и тегами для матчинга. Без хорошего
> каталога бот выдаёт абстракции — это сердце «продуктивности» платформы.

## Результаты фазы

- Развёрнутая БД (Supabase) по схеме `migrations/0001_init.sql`.
- Каталог: для MVP минимум **150–300 ролей**; стартовые 24 уже есть.
- Навыки (`skills`) и связи `occupation_skills` заполнены.
- `income_profiles` сверены с рынком (hh/Avito), помечены `source`/`updated_at`.
- `entry_paths` для ключевых ролей (что освоить, срок, вложения, первый шаг).
- `occupation_relations` для расширения горизонта в выдаче.

## Задачи

- [ ] Создать проект Supabase, применить миграции `0001` → `0002` → `0003`.
- [ ] Зарегистрироваться в O*NET Web Services / скачать bulk-базу.
- [ ] Импортёр O*NET → нормализация в `occupations`/`skills`/`occupation_skills`
      (берём RIASEC-коды и навыки из O*NET — экономит ручную разметку).
- [ ] Локализовать названия и `day_in_life` на русский для приоритетных ролей.
- [ ] Спарсить/занести ориентиры дохода РФ-рынка (hh, Avito) в `income_profiles`.
- [ ] Вручную добавить 30–50 ролей самозанятости/своего дела (нет в O*NET).
- [ ] Разметить `occupation_values`, `big_five_fit` (AI-ассист + ручная вычитка).
- [ ] Проставить `demand_level` по трендам/данным рынка.
- [ ] Скрипт валидации каталога (полнота полей, нет пустых RIASEC, есть income).

## Что собрать (данные)

- Доступ к O*NET (бесплатная регистрация разработчика).
- Источник зарплат/спроса РФ: hh.ru (API/выгрузки), Avito Услуги, Profi.ru.
- Список приоритетных профессий под выбранную аудиторию (Фаза 0).
- Юр-проверка лицензий источников (атрибуция O*NET, ToS hh/Avito).

## Зависит от

Фаза 0 (рынок/язык → какие данные о доходе и на каком языке).

## Критерий готовности

- В каталоге ≥150 активных ролей, у каждой: RIASEC-вектор, ≥3 навыка, ≥1
  income_profile, тип занятости, work_context.
- ≥30 ролей помечены как доступные для своего дела (`business`/`freelance`).
- Валидатор каталога проходит без ошибок.

## Риски

- Зарплаты быстро устаревают → заложить процесс обновления (Фаза 8).
- ToS бирж → предпочесть официальные API/ручной ввод ориентиров.

## Оценка

Импорт O*NET — 2–3 дня; локализация и доход топ-150 ролей — основная работа
фазы; роли самозанятости — вручную, по приоритету.
