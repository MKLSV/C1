# Источники данных и план наполнения каталога профессий

> Откуда брать профессии, навыки, зарплаты и спрос; что можно использовать
> легально; как наполнить каталог к запуску.

---

## 1. O*NET (США) — ядро каталога

Главная открытая база профессий Министерства труда США. ~1 000 профессий,
55 000+ работ; по каждой: задачи, навыки, знания, способности, инструменты и
технологии, требования к образованию, смежные профессии, RIASEC-коды (!).

**Доступ (оба варианта бесплатны, нужна регистрация разработчика):**
- **O*NET Web Services API** (v2.0) — актуальная база (вер. 30.3) в реальном
  времени, JSON, поиск по ключевым словам, есть код-примеры на GitHub для
  нескольких языков. → `services.onetcenter.org`.
- **Bulk download** — вся база как ~45 плоских текстовых файлов в одном ZIP,
  конвертируется в любую БД. → `onetcenter.org/database.html`.

**Лицензия:** контент O*NET доступен под открытой лицензией (O*NET Content
License) с требованием атрибуции. Перед публикацией свериться с
`onetonline.org/help/license`.

**Что берём из O*NET:** скелет профессий + RIASEC-коды (уже размечены!) + навыки
+ смежные роли. Это экономит ручную разметку `riasec_scores` и
`occupation_skills`.

---

## 2. ESCO (ЕС) — навыки и многоязычность

Классификация «профессии ↔ навыки ↔ квалификации», **27 языков**. Полезна для:
- единого справочника `skills` (один навык связывает много профессий —
  критично для транс­ферности),
- будущей локализации/масштабирования на другие языки.

---

## 3. Локальный рынок (РФ/СНГ) — доход и спрос

O*NET даёт структуру, но **не даёт зарплат и спроса для нашего рынка**. Источники:
- **hh.ru** — зарплаты, вакансии, требуемые навыки → `income_profiles`
  (`employee`), `demand_level`. (Есть API для работодателей/аналитики; проверить
  условия использования.)
- **Avito Услуги / Profi.ru / YouDo** — спрос и цены на самозанятость и услуги →
  `income_profiles` (`freelance`/`business`).
- **Upwork / Fiverr** — фриланс-ставки для цифровых профессий, мировой ориентир.
- **Профстандарты (Минтруд РФ)** — официальные описания трудовых функций.
- Аналитические отчёты (FlexJobs, Upwork In-Demand Skills, MBO Partners) — тренды
  спроса и роста (см. ниже).

> Важно: зарплаты/ставки быстро устаревают. Хранить с `source` и `updated_at`,
> обновлять периодически; в боте подавать как «ориентир», не как факт.

---

## 4. Дополнить тем, чего нет в гос-классификаторах: своё дело

O*NET/Профстандарты слабо покрывают самозанятость, ремесло, контент, микробизнес.
Эти роли добавляем вручную (см. стартовый каталог в
`migrations/0003_seed_catalog.sql`), опираясь на:
- категории соло-бизнеса (цифровые услуги, консалтинг/коучинг, обучение/курсы,
  контент-блог/YouTube/подкаст, e-commerce/handmade, локальные услуги, ремонт/
  реставрация, забота/репетиторство, нишевые B2B-сервисы);
- данные по доходу из Avito/Upwork/Fiverr.

## 5. Тренды спроса 2026 (для приоритизации каталога и аргументации)

- ~36% рабочей силы США уже работает независимо; число независимых работников с
  доходом >$100k удвоилось за 5 лет (до 5.6 млн в 2025).
- Самый быстрый рост и высокие ставки — AI/ML ($100k–$190k), кибербез
  ($85k–$150k), data science, разработка ПО, облака/блокчейн.
- Навыки с упоминанием AI выросли на 109% год к году (Upwork).
- Стабильный объёмный спрос — поддержка клиентов, медицина/уход, переводчики,
  дизайнеры, рекрутеры, проектные менеджеры, репетиторы/терапевты.

Используем это, чтобы (а) приоритетно наполнить каталог востребованными ролями,
(б) в боте честно показывать, где спрос растёт.

## 6. План наполнения к MVP

1. Импортировать топ-150–300 профессий из O*NET (с RIASEC-кодами и навыками)
   через bulk-download → нормализовать в `occupations` / `skills` /
   `occupation_skills`.
2. Локализовать названия и `day_in_life` на русский для приоритетных ролей.
3. Прогнать зарплаты/спрос РФ-рынка (hh/Avito) → `income_profiles`,
   `demand_level`.
4. Вручную добавить 30–50 ролей самозанятости/своего дела с `income_profiles` по
   фрилансу/бизнесу и `entry_paths`.
5. Разметить `occupation_values` и `big_five_fit` (можно AI-ассистом + ручная
   вычитка).
6. Проставить `occupation_relations` (смежные/alternative_mode) для расширения
   горизонта в выдаче.
