# Политика конфиденциальности (черновик для платформы «Компас»)

> ⚠️ Это рабочий черновик для MVP. Перед публичным запуском вычитать с юристом
> под выбранную юрисдикцию (РФ — 152-ФЗ; ЕС — GDPR). Версия согласия задаётся в
> `lib/consent.ts` (`CONSENT_VERSION`).

**Дата редакции:** 2026-06-30

## 1. Кто обрабатывает данные
Платформа «Компас» (далее — Сервис) — AI-собеседник для помощи в выборе
профессии. Оператор данных — _[указать юр-лицо/ИП]_.

## 2. Какие данные собираем
- Ответы в диалоге: интересы, навыки, опыт, ценности, пожелания по доходу и
  формату занятости, жизненная ситуация.
- Технические данные: идентификатор сессии, время, базовые логи.
- Контакты (email) — только если ты их явно укажешь (например, для отправки
  отчёта).

Мы не запрашиваем без необходимости ФИО, точный адрес и иные избыточные данные
(принцип минимизации).

## 3. Зачем
- Чтобы вести диалог и подобрать рекомендации профессий.
- Чтобы улучшать качество сервиса (в обезличенном виде).

Мы **не** гарантируем заработок и **не** ставим диагнозов — это поддержка в
выборе.

## 4. Передача третьим лицам
Текст диалога обрабатывается через API провайдера ИИ (Anthropic) для генерации
ответов. Мы настраиваем обработку так, чтобы данные API **не использовались для
обучения моделей**, и не передаём провайдеру лишних идентификаторов.

## 5. Хранение и защита
- Данные хранятся в защищённом виде (шифрование при передаче и хранении).
- _[Для РФ: хранение ПДн граждан РФ — на серверах в РФ, согласно 152-ФЗ.]_
- Срок хранения — не дольше, чем нужно для целей выше.

## 6. Твои права
- **Удаление:** ты можешь удалить данные сессии кнопкой «Удалить мои данные» или
  запросом на _[email оператора]_.
- Доступ к своим данным и отзыв согласия — по запросу.

## 7. Согласие
Перед началом диалога ты подтверждаешь согласие на обработку данных в указанных
целях. Версия согласия фиксируется (дата редакции выше).

## 8. Контакты
Вопросы по данным: _[email/форма оператора]_.
