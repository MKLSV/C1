# База знаний для платформы профориентации через диалог

> Назначение документа: собрать в одном месте всё, что нужно для проектирования
> платформы, которая через **интервью, наводящие вопросы и примеры** ведёт диалог
> с человеком, чтобы определить **конкретную профессию или дело** (включая
> самозанятость), которое ему нравится и на котором он может зарабатывать.
>
> Прошлый опыт человека — это плюс, но не ограничение: цель не «направление»
> (инженер), а конкретная роль/занятие (например, «инженер по контролю качества
> на пищевом производстве», «мастер по реставрации мебели», «таргетолог для
> локального бизнеса»).

---

## 1. Главная продуктовая идея и чем вы отличаетесь от существующих решений

Классические сервисы (CareerExplorer/Sokanu, Truity, Pymetrics, YouScience,
российский Profguide) работают по схеме **«тест → отчёт → список направлений»**.
Их слабые места, которые вы можете закрыть:

- Дают **широкие направления**, а не конкретную профессию/нишу.
- Это **анкета, а не разговор** — не умеют уточнять, копать вглубь, реагировать
  на ответ живым следующим вопросом.
- Почти всегда сводят результат к **найму**, игнорируя самозанятость, фриланс,
  микробизнес, ремесло, контент, консалтинг.
- Не связывают «что нравится» с «на чём реально можно зарабатывать сегодня».

**Ваше позиционирование:** адаптивный AI-собеседник, который через диалог и
примеры выводит человека на 3–5 конкретных способов зарабатывать на том, что ему
близко, с проверкой реалистичности (спрос, деньги, путь входа) — независимо от
того, наёмная это работа или своё дело.

---

## 2. Теоретический фундамент (на чём строить логику диалога)

Платформа должна опираться не на один тест, а на комбинацию проверенных моделей.
Каждая отвечает за свой «срез» человека.

### 2.1 RIASEC / Код Голланда (Holland Codes) — интересы и среда
Шесть типов личности и рабочих сред; совпадение типа человека и типа среды даёт
удовлетворённость и успех. Это «скелет» большинства профтестов мира (лежит в
основе Self-Directed Search и Strong Interest Inventory).

| Тип | Расшифровка | Тяготеет к |
|-----|-------------|-----------|
| **R** — Realistic | практик, «руки» | техника, природа, инструменты, физический труд |
| **I** — Investigative | исследователь | анализ, наука, данные, решение задач |
| **A** — Artistic | творец | дизайн, текст, музыка, самовыражение |
| **S** — Social | помогающий | обучение, забота, общение, сервис |
| **E** — Enterprising | предприимчивый | продажи, лидерство, убеждение, бизнес |
| **C** — Conventional | систематизатор | порядок, учёт, процедуры, данные |

Результат — трёхбуквенный код (напр. «AIS»), по которому подбираются занятия.
**Для вас RIASEC удобен как внутренняя система тегов профессий.**

### 2.2 Классификация Е.А. Климова (рус. традиция) — предмет труда
Пять типов по тому, **на что направлен труд** — хорошо ложится на русскоязычную
аудиторию и легко объясняется примерами:

- **Человек — Техника** (механик, инженер, водитель)
- **Человек — Человек** (учитель, врач, продавец, HR)
- **Человек — Знаковая система** (программист, бухгалтер, аналитик)
- **Человек — Художественный образ** (дизайнер, музыкант, актёр)
- **Человек — Природа** (агроном, ветеринар, эколог)

Инструменты: **ДДО** (дифференциально-диагностический опросник, 20 пар суждений),
«Определение типа будущей профессии», «Карта интересов». Это готовые проверенные
наборы вопросов, которые можно адаптировать под диалог.

### 2.3 Ikigai — соединение «нравится / умею / нужно миру / платят»
Идеальный смысловой каркас именно под вашу задачу, т.к. напрямую связывает
удовольствие и деньги. Четыре круга:

1. **Что вы любите** (энергия, интерес)
2. **В чём вы хороши** (навыки, таланты)
3. **За что платят** (рынок, спрос)
4. **Что нужно миру** (ценность для других)

Пересечение всех четырёх = устойчивое «дело жизни». Ключевой сдвиг вопроса:
не «какую профессию выбрать?», а **«какую жизнь я хочу, чтобы моя работа
поддерживала?»**. Используйте Ikigai как итоговую «проверку» каждой гипотезы о
профессии.

### 2.4 Big Five (OCEAN) — научная база личности
Самая валидированная модель личности (в отличие от популярного, но слабого по
надёжности MBTI). Пять черт: **O**penness, **C**onscientiousness,
**E**xtraversion, **A**greeableness, **N**euroticism. Помогает отсеять роли,
противоречащие складу человека (напр. высокая интроверсия + низкая стрессо-
устойчивость → холодные продажи скорее не подойдут). MBTI/DISC можно
использовать как «язык объяснения» для пользователя, но **решения принимать
на Big Five**.

### 2.5 Career Construction / Life Design (Марк Савикас) — нарративный подход
Самое важное для вашего «диалога через примеры». Идея: профессия конструируется
через **историю жизни человека**, а не вычисляется тестом. Знаменитое **Career
Construction Interview (CCI)** — 5 вопросов, каждый вскрывает скрытый слой:

1. **Ролевые модели в детстве** (кем восхищались) → каким человеком хочет стать,
   ядро самоидентичности.
2. **Любимые журналы / сайты / шоу / блоги** → какая среда и активности
   притягивают.
3. **Любимая история (книга/фильм)** → сценарий, по которому человек хочет
   прожить, способ преодоления трудностей.
4. **Любимая поговорка / девиз** → совет, который человек уже даёт сам себе.
5. **Ранние воспоминания** → главная «тема» и боль, которую человек хочет
   решить (часто превращается в призвание).

Это золото для вашего движка: вопросы открытые, дают богатый материал для AI,
и **выводят на конкретику** через личные образы, а не абстракции.

### 2.6 Motivational Interviewing (MI) — техника ведения разговора
Метод Миллера и Роллника. Каркас **OARS**:
- **O**pen questions — открытые вопросы (не «да/нет»).
- **A**ffirmations — подтверждение сильных сторон, поддержка.
- **R**eflective listening — отражение («правильно понимаю, что вам важно…»).
- **S**ummaries — резюмирование сказанного.
- **+ Change talk** — подведение к словам самого человека о желаемых изменениях.

Это **готовый стиль для вашего бота**: тёплый, не давящий, вытягивающий
мотивацию из самого пользователя.

## 3. Архитектура диалога (как вести интервью)

Рекомендуемая воронка из этапов. Бот не задаёт всё подряд — он адаптивно
выбирает следующий вопрос по предыдущим ответам.

### Этап 0. Раппорт и контекст
Снять давление, объяснить формат, узнать ситуацию: возраст/этап, текущая
занятость, что болит («не знаю чего хочу» / «выгорел» / «хочу своё дело» /
«хочу больше денег» / «школьник перед выбором»).

### Этап 1. Интересы и энергия (что нравится)
Открытые + нарративные вопросы (RIASEC + CCI + Ikigai-«люблю»):
- «Расскажите про занятие, за которым вы теряете счёт времени.»
- «Что вы делаете в выходные, когда никто ничего не требует?»
- «За каким контентом/каналами/блогами вы залипаете? О чём они?»
- «Кем вы восхищались в детстве и за что именно?»
- «Что люди обычно просят вас помочь сделать или объяснить?»

### Этап 2. Навыки и сильные стороны (в чём силён)
Транс­ферные навыки из любого опыта — работа, учёба, хобби, быт, волонтёрство:
- «Вспомните задачу, которой вы гордитесь. Что именно вы сделали по шагам?»
- «За что вас хвалили коллеги/учителя/друзья?»
- «Что даётся вам легче, чем большинству вокруг?»
Важно: навыки **не обязаны** быть связаны с желаемым делом — это сырьё, а не
рамка.

### Этап 3. Ценности, стиль жизни, ограничения (контекст)
- Деньги: какой доход «достаточно» и «хорошо»?
- Формат: наём / фриланс / своё дело / удалёнка / руками / с людьми / в одиночку?
- Риск и стабильность, география, время, здоровье, забота о семье.
- Big Five-сигналы: интроверсия/экстраверсия, отношение к рутине и риску.

### Этап 4. Генерация гипотез (примеры профессий)
Бот предлагает **конкретные** варианты с примерами и «примеркой»:
- «Звучит как Х. Вот как выглядит обычный день такого человека… Откликается?»
- Показывает 2–3 непохожих сценария (наём / своё дело / гибрид), чтобы
  расширить картину.
- Реакция пользователя («да, но…», «нет, потому что…») — главный сигнал для
  следующей итерации.

### Этап 5. Проверка реальностью (на чём заработать)
Для каждой выжившей гипотезы:
- **Спрос:** есть ли вакансии / заказы (Upwork, Fiverr, hh, Avito-услуги).
- **Деньги:** диапазон дохода, модель оплаты (зарплата / за проект / за час /
  подписка / продукт).
- **Путь входа:** что освоить, за какой срок, минимальные вложения, первый шаг.
- **Ikigai-проверка:** сходятся ли все 4 круга.

### Этап 6. План действий
3–5 финальных вариантов, ранжированных, с конкретным первым шагом на эту неделю
(«сделать тестовую услугу», «поговорить с 5 потенциальными клиентами»,
«пройти курс Х», «собрать портфолио из 3 работ»).

## 4. Банк вопросов (заготовки для движка)

Сгруппировано по цели. Каждый вопрос помечен моделью-источником.

**Раскрытие интересов (RIASEC/Ikigai/CCI)**
- О чём вы можете говорить часами?
- Какую проблему в мире вам хотелось бы, чтобы кто-то наконец решил?
- Если бы деньги были не важны год — чем бы вы занялись?
- Какие задачи на прошлой работе/учёбе вы ждали, а какие оттягивали?

**Раскрытие навыков (Transferable skills)**
- Назовите 3 дела, за которые вам платили или просили совета в последний год.
- Что вы умеете чинить, организовывать, объяснять, создавать?
- Какой инструмент/программа/ремесло вы освоили без принуждения?

**Ценности и деньги (Ikigai/MI)**
- Что для вас «успех» через 5 лет — словами, не цифрами?
- Сколько денег в месяц = «спокойно»? А «отлично»?
- Вы хотите делать что-то руками, головой, с людьми или в одиночку?

**Нарратив/идентичность (CCI Савикаса)**
- Любимая книга или фильм — о чём он и почему цепляет?
- Ваш девиз по жизни?
- Самое раннее воспоминание, которое всплывает первым?

**Расширение горизонта (анти-стереотип)**
- Какую работу вы считаете «не для вас» — и почему именно?
- Знаете ли вы, что на хобби Х люди зарабатывают так-то? (примеры)

## 5. Самозанятость и своё дело (обязательный блок — конкурентов мало)

Платформа должна одинаково хорошо вести и к найму, и к собственному делу.

**Типы независимой занятости** (важно различать в диалоге):
- **Фрилансер** — продаёт время/навык по проектам (дизайн, тексты, монтаж).
- **Solopreneur** — бизнес из одного человека, ищет стабильный доход и свободу.
- **Консультант/эксперт** — монетизирует глубокую экспертизу (часто $150–500/час).
- **Создатель контента** — аудитория → реклама, спонсорство, партнёрки, продукты.
- **Ремесленник/локальный сервис** — руками или услуга в своём городе.

**Факты для аргументации пользователю (снимают страх):**
- ~Половина соло-предпринимателей стартуют с вложениями < $5 000.
- ~77% выходят в прибыль в первый год.
- Цифровые услуги (тексты, дизайн, SMM, SEO, AI-контент) дают валовую маржу
  80–94%; один SMM-специалист — $2 000–5 000 с клиента в месяц.

**Как помочь найти идею дела (встроить в диалог):**
1. Выписать 3–5 навыков, за которые уже платили или просили совета.
2. Проверить спрос: «навык + freelance» на Upwork/Fiverr/hh/Avito.
3. Поговорить с 5–10 потенциальными клиентами до любых вложений.
4. Пред-продать услугу через простой лендинг — проверить реальный спрос.

Категории идей для подсказок: цифровые услуги, консалтинг/коучинг, обучение и
курсы, контент (блог/YouTube/подкаст), e-commerce/handmade, локальные услуги,
ремонт/реставрация, забота (уход, репетиторство), нишевые B2B-сервисы.

## 6. Источники данных о профессиях (чем наполнять базу и проверять реальность)

Чтобы выдавать **конкретные** профессии с зарплатами и навыками, нужен
структурированный справочник занятий. Лучшие открытые источники:

- **O*NET (США, англ.)** — главная открытая база: ~1 000 профессий, 55 000+
  работ, по каждой: задачи, навыки, знания, инструменты/технологии, требования,
  смежные профессии. Есть для машинного использования (таблицы, кросс-связи).
  Идеально как ядро вашего каталога и системы тегов.
- **ESCO (ЕС, 27 языков)** — классификация «профессии ↔ навыки ↔ квалификации»,
  многоязычная (важно, если будете масштабироваться). Хорошо для skills-matching.
- **Локальные рынки:** для РФ/СНГ — данные hh.ru (зарплаты, вакансии, навыки),
  Avito Услуги (спрос на самозанятость), Профстандарты; для проверки спроса
  фриланса — Upwork, Fiverr, профильные биржи.

Рекомендация по архитектуре данных: профессия = запись с полями
`название`, `RIASEC-код`, `тип по Климову`, `ключевые навыки`, `день из жизни`,
`модель дохода`, `диапазон $`, `путь входа`, `наём/соло/оба`, `смежные роли`.
Тогда AI сможет матчить профиль пользователя с каталогом и объяснять «почему».

## 7. Как технически устроить AI-собеседника

- **Стиль (MI/OARS):** тёплый, без оценок, открытые вопросы, отражение,
  резюме, подведение к решению самим пользователем.
- **Адаптивность:** следующий вопрос выбирается по предыдущим ответам, а не по
  фиксированному списку — это ваше главное отличие от анкет.
- **Профиль пользователя как state:** накапливайте по ходу диалога теги —
  RIASEC, навыки, ценности, ограничения, доход-цель, формат занятости.
  На каждом шаге обновляйте и используйте для подбора.
- **«Объясняй через примеры»:** на каждую гипотезу — «день из жизни», реальные
  истории, диапазон дохода, первый шаг. Это снижает абстрактность.
- **Петля проверки:** гипотеза → реакция пользователя → уточнение → проверка
  спроса/денег → план. Не один проход, а итерации.
- **Опора на данные:** ответы про зарплаты/спрос/навыки — из каталога
  (O*NET/ESCO/hh), а не из «головы» модели, чтобы не выдумывать.
- **Модель:** для качественного эмпатичного диалога и рассуждений — топовые
  модели Claude (например, Claude Opus 4.8) через Claude API / Agent SDK.
- **Этические рамки:** не давить, не обещать заработок гарантированно, помечать,
  что это поддержка в выборе, а не диагноз; сложные/кризисные случаи (выгорание,
  отчаяние) — мягко направлять к живому специалисту.

---

## 8. MVP — с чего начать

1. Один сценарий диалога (этапы 0–6) на 15–25 адаптивных вопросов.
2. Каталог из 100–300 конкретных профессий/занятий с тегами RIASEC + Климов,
   доходом, путём входа, флагом наём/соло (можно начать с выгрузки O*NET +
   ручная локализация топ-профессий под ваш рынок).
3. Профиль-state пользователя, который наполняется по ходу.
4. Финальный отчёт: 3–5 конкретных вариантов, ранжир, первый шаг.
5. Обязательный блок «своё дело/самозанятость» наравне с наймом.
