# Рубрика извлечения профиля + банк интересов RIASEC

> Как превращать свободные ответы пользователя в структурированные теги профиля.
> Используется LLM (по инструкции в системном промпте) и для офлайн-проверки.

---

## 1. RIASEC: банк активностей и шкала

Классический тест — 48–60 пунктов вида «насколько вам понравилось бы…», ответ по
шкале **нравится / не уверен / не нравится** (или 1–5). Каждый пункт прибавляет
балл одному из шести типов. В разговорном боте мы не зачитываем 60 пунктов — мы
**слышим эти активности в свободных ответах** и начисляем баллы. Ниже — опорные
маркеры по типам (для кодирования ответов и, при желании, для быстрых уточняющих
карточек «что из этого вам ближе»).

| Тип | Маркеры в речи / активности |
|-----|------------------------------|
| **R — Realistic (Doers)** | чинить, собирать, строить, водить, работать руками/инструментами/техникой, на улице, с растениями/животными, спорт |
| **I — Investigative (Thinkers)** | разбираться «почему», анализировать, исследовать, считать, читать, эксперименты, решать сложные задачи, данные |
| **A — Artistic (Creators)** | рисовать, писать, музыка, видео, дизайн, придумывать, импровизировать, эстетика, самовыражение |
| **S — Social (Helpers)** | учить, помогать, заботиться, объяснять, общаться, поддерживать, работать с людьми, волонтёрить |
| **E — Enterprising (Persuaders)** | продавать, убеждать, вести за собой, организовывать, запускать, рисковать, договариваться, лидировать |
| **C — Conventional (Organizers)** | упорядочивать, вести учёт, следовать процедурам, таблицы, точность, планирование, администрирование |

**Начисление в боте:** за каждый явный маркер в ответе +1…+3 соответствующему
типу в `riasec_delta` (сила сигнала: мимоходом +1, ярко/повторно +2–3). Итоговый
код = топ-3 типа из накопленных `riasec_scores`.

> Стандартные опросники: 48 пунктов (3 ответа: like/unsure/dislike) или 60
> пунктов (по 10 на тип). Можно встроить как опциональный «быстрый режим» —
> карточки активностей вместо разговора.

## 2. Классификация Климова (предмет труда)

| Тип | Кодируем `klimov_delta` при сигналах |
|-----|--------------------------------------|
| `tech` (Человек–Техника) | техника, механизмы, инструменты, производство |
| `human` (Человек–Человек) | люди, обучение, забота, продажи, сервис |
| `sign` (Человек–Знак) | числа, тексты, код, схемы, данные, документы |
| `art` (Человек–Образ) | искусство, дизайн, музыка, контент, эстетика |
| `nature` (Человек–Природа) | растения, животные, экология, агро |

RIASEC и Климов частично перекрываются — ведём оба, они дают независимые срезы и
повышают точность матчинга.

## 3. Навыки (transferable) — структура записи

Из любого ответа о «делал / умею / гордился» извлекать:
```jsonc
{ "skill": "<глагол+объект, конкретно>",  // "монтировать видео", "вести переговоры"
  "evidence": "<откуда: работа/хобби/учёба/быт/волонтёрство>",
  "paid": true|false,                       // платили или просили совета → кандидат в монетизацию
  "level": "basic|confident|expert" }
```
Правило: навык — **бонус при матчинге, не фильтр**. Отсутствие навыка не
исключает профессию, если есть короткий путь входа.

## 4. Big Five — сигналы из речи (не тест)

Ловим осторожно, как мягкие сигналы (`big_five_signals`), для отсева явно
конфликтных ролей, а не как приговор:
- **Extraversion:** «заряжаюсь от людей» (high) ↔ «устаю от общения» (low).
- **Openness:** «люблю новое/идеи/эксперименты» (high) ↔ «люблю привычное» (low).
- **Conscientiousness:** «люблю порядок/планы/довожу до конца» (high).
- **Neuroticism/стресс:** «тяжело переношу неопределённость/давление» (→ риск low).
Big Five — научно надёжнее MBTI; MBTI/DISC можно использовать только как «язык
объяснения» пользователю, но не для решений.

## 5. Ценности и ограничения

`values`: помощь людям, свобода графика, стабильность, творчество, статус, рост
дохода, влияние, автономия, спокойствие, признание, польза обществу.

`constraints`:
- `income_floor` / `income_goal` — «спокойно» и «отлично», числом (валюта рынка).
- `format`: `remote|office|hands|with_people|solo|team` + `employee|freelance|
  business|hybrid`.
- `risk_tolerance`: low|medium|high.
- `geo`, `time_to_invest`, прочие ограничения (здоровье, семья).

---

## 6. Гипотезы — жизненный цикл

```
pending → (показали пример) → positive | interested_but(+objection) | negative
positive        → status: alive  (углубляем, ведём в reality_check)
interested_but  → адресуем objection данными; затем positive/negative
negative        → status: dropped (спросить почему → уточнить values)
финал           → status: final  (попадает в recommendations)
```

---

## 7. Мини-валидация качества извлечения (для тестов)

Чек-лист, что профиль собран корректно перед финалом:
- [ ] `riasec_scores` имеет выраженный топ-3 (не всё по нулям/поровну).
- [ ] ≥3 навыка, из них ≥1 с `paid:true`.
- [ ] заданы `income_floor`, `income_goal`, `format`.
- [ ] ≥3 `hypotheses` со `status:alive`, среди них есть и наём, и своё дело.
- [ ] у каждой финальной гипотезы есть `rationale` и `first_action`.
